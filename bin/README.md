# bin/nssm.exe

[nssm — the Non-Sucking Service Manager](https://nssm.cc/)，用于把 `xunfei-proxy.js` 注册为 Windows 系统服务（开机自启 + 崩溃重启）。

本目录已附带一份官方发布的 `nssm.exe`（x86-64），`service.ps1` 直接调用它，无需额外安装。

- 官方下载：<https://nssm.cc/download>
- 源码 / 发行版：<https://git.nssm.cc/nssm/nssm> / <https://nssm.cc/release/nssm-2.24.zip>
- 许可证：见 nssm 自带的 `LICENSE`（随发行版附带）

> 在意供应链安全的用户可自行从官网下载并替换本文件，版本与签名以官网为准。
